## Aim

Allows easy setup of plugins for supercharging work with AI.

- needs to work on MacOS, Windows and Ubuntu
- should support various starter packs depending on the type of work done. So - modular
- main areas it should help in are:
  - system design
  - software design
  - ui design
  - planning work (specs)
  - building software
  - maintaining software
  - testing and understanding software
  - research
  - ai use evaluation and optimization

For now, installation should be easy in Claude Code, Claude Cowork, Codex, Cursor, and possibly Grok (not installed yet).
